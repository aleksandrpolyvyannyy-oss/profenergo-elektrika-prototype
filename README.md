# Прототип: Сайт 2. Электрика частного дома, щиты, подключение участка, подсветка

Серый каркас (wireframe) многостраничного сайта. Статический HTML, один файл стилей `assets/style.css`,
все ссылки относительные, внешних библиотек нет. Папку можно выложить на любой хостинг как есть
или открыть с диска: `index.html` - главная.

Страниц: 66 (волна 1: 16, волна 2: 20, волна 3: 30 (из них статей 8, условных 14)).

| Волна | Страниц |
|---:|---:|
| 1 | 16 |
| 2 | 20 |
| 3 | 30 |

- Волна 1 - страницы по ТЗ на тексты: реальные H1 и блоки, черновые подписи, данные Антона в [квадратных скобках].
- Волны 2 и 3 - каркасы без текста: H1 из дерева страниц, блоки по типу шаблона (услуга, хаб, статья, район,
  карточка товара) с серыми заглушками, ссылки на соседние страницы и кнопка расчёта.
- Тёмная полоса вверху каждой страницы - служебная: волна, «условная», тип шаблона, источник.
- Фото - серые заглушки: на сайт идут только реальные фото объектов.

Сборка: `прототип/build.py` (данные - `ТЗ_тексты`, деревья в `ИТОГ_ядро.md`, `pages_site*.py`).
Страницы закрыты от индексации (`noindex`), это прототип.
